# Golden Hour Pond (Three.js)

A stylized low-poly meadow with a calm pond at golden hour. Everything is procedural and lives in a single `index.html` (Three.js loaded from a CDN).

Features: trees, mossy rocks, dense grass with flowers, reeds and lily pads, butterflies and birds, a wooden dock with a bench, planar water reflections, bloom.

Controls: drag to orbit · **F** toggles walk mode (WASD + mouse, Shift to run) · **P** saves a screenshot · **H** hides the HUD.

Live: https://itsmeeudrino.github.io/meadow-pond-threejs/
